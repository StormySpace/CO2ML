This is the machine learning code for the prediction of thermosphreic CO2 cooling emission observations by NASA's TIMED/SABER satellite. The paper is published in the journal "Advances in Space Research".
Bag, T., et al.(2026), Prediction of thermospheric CO2 emission using Machine Learning Technique,77, 3499-3507, Doi:10.1016/j.asr.2025.11.070
